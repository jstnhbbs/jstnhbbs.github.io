FEATURED PROJECT 2026 — ONGOING

Tugboat.

A shared home for a family’s day.

Calendars, routines, chores, and meal plans belong together. Tugboat brings them into one household dashboard, with a native app for iPhone and iPad and a shared backend.

I started with a web application, then evolved the main experience into SwiftUI. The Next.js backend continues to handle accounts and household data through a mobile REST API.

BEHIND THE BUILD

One product.
Two different contexts.

A shared iPad and a parent’s phone serve different purposes. Tugboat’s interface adapts to both: more room for the week on a tablet, and focused views for checking in on a phone.

Native where it matters

SwiftUI provides the iPhone and iPad experience. EventKit brings in calendars already configured on the device.

A shared source of truth

A Next.js API and Turso database connect household members, routines, chores, recipes, and meal plans across devices.

Built around a household

Account authentication, member roles, and household permissions support the different people using the same family dashboard.
